# Съёмка на настоящем пианино — карточка для Камилы (02.11.2026, вечер)

Цель: первая запись с очков, по которой подбираем порог DINO «палец на клавише» и
проверяем привязку клавиатуры к кадру. Один клип 40–60 с, лучше два дубля.

1. Сесть как обычно. Смотреть на руки, а не в ноты: клавиатура поперёк кадра, видны обе руки.
2. 5 секунд руки на коленях, клавиатура пустая (нужен «спокойный» вид клавиш).
3. Начало «К Элизе» по одной ноте, медленно, примерно нота в секунду, каждую подержать:
   E5 D#5 E5 D#5 E5 B4 D5 C5 A4 — правой рукой, потом ещё раз.
4. Затем «К Элизе» в обычном темпе, 15–20 с, обе руки.
5. Свет комнатный, фонарик не нужен. Головой резко не крутить.

Файл с очков прислать как есть (mp4). Приём: `python keys/ingest_clip.py <файл>` → кадры 10 fps
→ `press_dino.py` → порог.
