EN — Operator: Enter the token for your role (Maestro token for Maestro, Artist token for Artist). The token stays in memory only — never in the URL or storage. Role is derived by the server from the token; the selector only changes this view. Maestro creates/starts/completes sessions, sends as Maestro, and approves drafts. Artist sends only as Artist and sees only approved deliveries. Text-only EN↔VI interpretation; no registration, votes, audio or media. Drafts are visible only in the Maestro view.

RU — Оператор: Введите токен своей роли (Maestro — токен Maestro, Artist — токен Artist). Токен хранится только в памяти — не в URL и не в хранилище. Роль определяет сервер по токену; переключатель меняет только отображение. Maestro создаёт/запускает/завершает сессии, отправляет как Maestro и одобряет черновики. Artist отправляет только как Artist и видит только одобренные доставки. Только текстовый перевод EN↔VI; без регистрации, голосований, аудио и медиа. Черновики видны только в виде Maestro.
